# Kit de marca · Pimentones La Cajita

Logo reconstruido en vector a partir del original (300 px). El dibujo se redibujó siguiendo el trazo original con **grosor variable de pincel** (afina en las puntas, como el dibujo a mano) y el texto se recompuso con tipografías geométricas equivalentes convertidas a contornos. La composición quedó centrada ópticamente; los colores se midieron en el centro del trazo original. Los SVG se escalan a cualquier tamaño sin perder nitidez; los PNG están exportados en alta resolución con fondo transparente.

## Archivos
- `logo-vertical.svg` / `.png` (1024, 2048, 4096 px): versión principal, dibujo arriba y texto abajo.
- `logo-horizontal.svg` / `.png` (2048, 4096 px): para encabezados, firmas de correo, facturas.
- `*-fondo-blanco.png`: con fondo blanco, para documentos.
- `*-blanco.svg` / `*-blanco-2048.png`: todo en blanco, para fondos oscuros o fotos.
- `*-negro.svg`: una sola tinta, para sellos, bordados y grabado.
- `isotipo.svg` / `isotipo-*.png`: solo el dibujo, para redes sociales, favicon y etiquetas pequeñas.
- `icon-192.png`, `icon-512.png`, `favicon.png`: íconos de la app y del navegador.
- `og-logo.jpg`: imagen 1200×630 para compartir enlaces.

## Colores
- Rojo pimentón: `#D42027` (RGB 212, 32, 39), medido en el centro del trazo del original
- Verde tallo: `#239A46` (RGB 35, 154, 70)
- Tinta (versión negra): `#1A1714`

## Tipografías equivalentes
- "PIMENTONES": Jost Bold (equivale a Futura/Century Gothic Bold).
- "LA CAJITA": Questrial (equivale a Century Gothic).
Si el negocio conserva el archivo de la tipografía original, el texto se regenera con `build_logo.py` cambiando una línea.

## Uso mínimo
Altura mínima recomendada: 24 px para el logo horizontal, 48 px para el vertical, 16 px para el isotipo. Área de protección: la altura de la letra "L" alrededor del logo.
