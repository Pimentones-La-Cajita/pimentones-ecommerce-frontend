# 🌶️ Pimentones La Cajita · eCommerce Frontend (Storefront)

Frontend público de comercio electrónico para la venta de conservas artesanales de pimentón.

## 📦 Características
* **Catálogo & Degustación:** Fichas de los 4 productos de pimentón con notas de cata e ingredientes reales.
* **Guía Interactiva de Maridaje:** Recomendaciones gastronómicas con quesos madurados, tablas de jamones y panes rústicos.
* **Armador de Cajas:** Experiencia personalizada para combinar sabores en cajas de regalo o consumo familiar.
* **Carrito & Checkout:** Integración con cotización de envíos por ciudades y pasarela Wompi (tarjetas, PSE, Nequi).
* **Rastreo en Tiempo Real:** Estado de despacho para compradores vía código de orden.
* **Asistente Sommelier IA & WhatsApp:** Canales de atención interactiva.

## 🚀 Inicio Rápido
``bash
npm install
npm run dev
``
Disponible en: [http://localhost:3000](http://localhost:3000)
